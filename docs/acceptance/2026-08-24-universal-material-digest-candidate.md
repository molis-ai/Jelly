# 灵感材料提炼候选验收记录（2026-08-24）

## 结论与边界

当前候选已经形成可用闭环：用户先保存原始材料，Jelly 不自动生成摘要；用户明确点击“提炼这份材料”后，系统读取来源、保存可追溯的材料快照，再生成简体中文摘要。来源读取失败时原始材料仍保留，并给出恢复动作。

这不是“10 分体验已经验收”的结论。直接文字、真实 TXT 文件和小红书受限页已在最终业务二进制中实操；HTML、Markdown、图片、PDF、音频、视频及小红书公开成功页目前只有工程验证或离线夹具证据。小红书真实成功样本、所有格式的最终 App 实操和用户主观体验仍为 `UNVERIFIED`。

## 复杂度审查结果

### 当前必须

- 统一 URL、直接文字和本地文件的“保存原文 → 手动提炼 → 审阅 → 写入笔记”路径。
- 为 TXT/Markdown、HTML、图片、PDF、音频和视频提供受限提取器，并保留来源定位信息。
- 长材料采用受控分段与综合，模型输出必须引用真实材料块。
- 小红书只读取公开页面，严格校验 note ID；正文、图集和视频走同一个材料快照合同。
- 对受限、不可用、内容不足、模型未配置和处理中断提供明确状态及恢复动作。
- 原文变化时让旧摘要失效并停止旧流水线，避免旧结论继续显示或保存失败。

### 可以延后

- 为每一种格式补齐最终 App 的真实样本矩阵和性能基线。
- 在合法、稳定的公开成功样本上完成小红书图文和视频端到端实操。
- 更丰富的文件拖放、批量导入和来源专属预览。

### 应当删除

- 捕获链接后自动生成摘要。
- 为未知来源增加平台专属服务或不可回滚的抓取依赖。
- 在没有真人证据时宣称“10 分体验”或“全部格式均已产品实操通过”。

## 本次实现

- 捕获后默认只保存原始链接、文字或文件引用，不自动调用模型。
- 统一的手动提炼动作、进度、取消、重试、重新读取来源和模型下载授权。
- 直接文字、TXT/Markdown、公共 HTML、图片 OCR、PDF 文本/OCR、音频转写、视频音轨与关键帧 OCR。
- 长材料分段提炼与综合；摘要结论、要点、章节、引用和排除项均绑定材料块 ID。
- 派生摘要使用简体中文；原文引用和完整材料保持原语言。
- 小红书精确路径识别、公开页解析、图集/视频组合提取、请求大小限制及私网地址防护。
- 小红书受限或不可用时显示“粘贴文字”“选择文件”“重试读取”，并保留原始链接。
- 摘要写入笔记时先保留来源，再写核心观点、要点、章节、引用、覆盖范围和未纳入内容。
- 编辑已提炼的直接文字时，原文能够正常保存，旧摘要和旧流水线同步失效。
- V4 工作区在读取时迁移到 V5 的材料快照与证据合同；旧版 App 不能作为 V5 数据的写入方。

## 产品实操

实操使用 Release 业务二进制的隔离副本；仅为避免与本机其他 Jelly 进程及正式数据冲突而更换测试 Bundle ID 并重新签名，业务代码未替换。

实操结束后又补了两项防御性修正：兼容接口忽略 JSON Schema 时的嵌套字段长度复核，以及编辑已提炼文字时旧摘要失效并停止旧流水线。两项均已通过自动化并进入重新构建、重新签名的最终候选，但没有再把下列整套 UI 旅程重跑一遍；因此最终包的完整产品实操仍不能扩大为全部通过。

- 直接文字：保存后显示“尚未提炼”，没有自动摘要；手动点击后由真实 MiniMax 生成有原文依据的中文摘要。
- TXT 文件：从系统文件选择器导入真实文本文件，手动提炼成功，文件名和摘要均可见。
- 小红书：对用户样本的同一公开 note path 读取到“页面不见了”状态；原始链接保留，恢复动作可见，失败状态不会被其他材料的成功提示污染。
- 写入笔记：直接文字以原文开头，文件以文件名开头，后续附结构化摘要和“未纳入摘要”；笔记可以正常打开。
- 重启恢复：三类材料、摘要和失败状态在隔离数据目录中恢复成功。

未实操：小红书公开成功页、HTML、Markdown、图片、PDF、音频和视频的最终 App 端到端路径；中文输入法手感、视觉质感和用户是否认为达到 10 分也均为 `UNVERIFIED`。
